The code in `upload` runs on a Pololu 3pi+ 2040 Robot. This robot uses a Raspberry Pi RP2040 microcontroller. This is the documentation for the robot:

https://www.pololu.com/product/5001/resources

Code examples live here: https://github.com/pololu/pololu-3pi-2040-robot

The robot has been equipped with three maxbotix MB1360 XL-MaxSonar-AEL0 sonar sensors. Two to act as ears and one to act a mouth (emitter):

https://maxbotix.com/products/mb1360
